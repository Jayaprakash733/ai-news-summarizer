# AI News Summarizer

A Streamlit application that fetches the latest AI news using Tavily Search and summarizes it using Mistral AI via LangChain.

## Features
- 🔍 Latest AI news search
- 🤖 AI-powered summarization
- 📰 Bullet-point summaries
- 📖 View raw search results
- 🎨 Modern Streamlit interface

## Tech Stack
- Python
- Streamlit
- LangChain
- Mistral AI
- Tavily Search
- python-dotenv

## Installation

```bash
pip install -r requirements.txt
streamlit run newssummarizer.py
